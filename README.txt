# Gold Soccer Sim 

Football match predictor using xG stats + Poisson distribution.
Covers Premier League, Serie A, La Liga, and Bundesliga.

## Setup
pip install pandas numpy scipy openpyxl jupyter

## Usage
1. Update `football_data.xlsx` with current team stats
2. Open `GoldSoccerSim.ipynb` in Jupyter
3. Edit the `get_match_prediction()` calls at the bottom
4. Run all cells
